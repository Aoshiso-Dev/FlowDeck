# M5GOファームウェア

FlowDeckの状態表示と操作を行う任意の端末用ファームウェアです。PCアプリはM5GOなしでも利用できます。

対象は320×240の画面と物理A/B/Cボタンを持つオリジナルM5GO（ESP32、4MB flash）です。M5GO2／Core2向けのタッチUIではありません。

## 機能

- USB、または2.4GHz Wi-Fi STA / TLSによるPCとの接続
- 温度・ファン回転数の表示、ファンの自動／手動操作
- 照明グループ・シーン、明るさ、消灯／復帰、同期停止の操作
- 対応PCとの組合せで本体LEDを照明へ同期（初期状態と再接続後はOFF）

Wi-Fiの接続情報とPCの認証情報は、WindowsアプリからUSB経由で登録します。通信切断時は編集中の操作を破棄し、未取得の温度・回転数を表示し続けません。再接続時に操作を再送しません。

| 画面 | A | B短押し | C | B長押し |
| --- | --- | --- | --- | --- |
| ホーム | 自動 | 手動／異常詳細 | 照明 | マザーボード監視 |
| 自動 | 前の候補 | 適用 | 次の候補 | 破棄してホーム |
| 手動 | −5ポイント | 一括適用 | ＋5ポイント | 破棄してホーム |
| 照明メニュー | 前の項目 | 決定 | 次の項目 | ホーム |
| グループ／シーン | 前の候補 | 選択／適用 | 次の候補 | 破棄してホーム |
| マザーボード監視 | 前のページ | 戻る | 次のページ | 戻る |

## ビルド

リポジトリのルートからPowerShellで実行します。

```powershell
python -m venv .tools/platformio
./.tools/platformio/Scripts/python.exe -m pip install platformio==6.1.18
./scripts/build-firmware.ps1
```

`platformio.ini`でEspressif32 6.12.0、M5Unified 0.2.23、M5GFX 0.2.30、ArduinoJson 7.4.2を固定しています。日本語描画にはM5GFXのefontJAを使います。

ビルドスクリプトは既定の`N:`を一時的に割り当て、日本語パスに対応しないツールチェーンへ短いパスを渡します。使用中なら`-DriveLetter`で別の空いているドライブ文字（D〜Z）を選んでください。生成物は`firmware/m5go/.pio/build/m5go`に保存します。引数なしではビルドだけを行い、端末には書き込みません。

## 書き込み

対象のM5GOとCOMポートを実物・デバイスマネージャーで確認し、PCアプリのM5GO通信を切断します。必要なバックアップを取ったうえで、`scripts/build-firmware.ps1`の`-UploadPort`へ確認したCOMポートを渡してください。転送速度は115200 baudです。

書き込みは既存ファームウェアを置き換えます。`partitions.csv`はアプリ領域3MiBの構成なので、異なるパーティション構成から移行する際はアプリ単体の更新と混同しないでください。

ソースとビルド設定を公開しており、生成済みバイナリは提供していません。コンパイル成功・ホスト上の模擬試験だけでは、実機の表示、ボタン、USB、Wi-Fi、LEDの動作を検証したことにはなりません。
